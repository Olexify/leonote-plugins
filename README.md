# Leonote plugins

The list of plugins the Leonote app shows in Settings › Plugins › Search plugins. Leonote reads `plugins.json` only
when someone opens that search.

- To add or update a plugin, open a pull request that changes its row in `plugins.json`. `plugins.template.json` shows
  a row; `LIST-RULES.md` says what a plugin on the list must do.
- To report a plugin, open an issue.

Plugins are made by other people. Leonote does not make, check or endorse them, except a version marked verified, and
that mark covers only what `LIST-RULES.md` says. It is no guarantee.
